# 预设

预设决定一轮故事使用哪些提示词、如何整理历史，以及是否更新世界状态和生成行动建议。会话使用绑定的预设；开始生成后，本轮配置保持不变，后续修改从下一轮生效。

## 提示词节点

预设由一层有序条目组成，每个条目保存完整的提示词模板。固定系统节点依次为：主提示、用户信息、角色信息、世界书、会话历史、用户输入；这六个节点始终启用。世界状态、行动建议是可选的后置处理节点，依次排在用户输入之后。

自定义节点可以插入列表开头、任意两个节点之间或列表末尾，通过拖动和上移、下移调整位置。系统节点保持既定相对顺序，自定义节点的位置按保存的列表顺序执行。保存时发现系统节点乱序会提示错误，不自动重排条目。

所有节点的提示词都可以编辑。系统节点的身份、消息角色与必需启用规则保持固定，自定义节点可选择 System、User 或 Assistant 角色。空的普通提示词不会单独生成消息；会话历史与用户输入仍需保留各自的结构变量。

## 系统变量

在提示词中填写 `{{变量名}}`，本轮构建上下文时会读取对应材料。普通文本变量可以在任意节点引用。

| 变量 | 内容 |
| --- | --- |
| `{{user}}` | 当前玩家名称 |
| `{{persona.prompt}}` | 当前玩家通过加载规则的角色提示词 |
| `{{characters.prompts}}` | 其他激活角色的提示词，按顺序排列 |
| `{{world.lore}}` | 激活的世界书正文 |
| `{{history.summary}}` | 本轮采用的有效摘要，没有摘要时为空 |
| `{{history.messages}}` | 保留的原角色历史消息，不含摘要 |
| `{{input.text}}` | 本轮接受的用户输入原文 |
| `{{state.currentValues}}` | 本轮可更新状态的当前值 |
| `{{state.updateRules}}` | 同一组可更新状态的规则 |

`{{history.messages}}` 只能在会话历史节点中出现一次，按原来的 User、Assistant 角色展开；该节点中的普通文字和摘要作为 System 消息。用户输入节点必须包含一次 `{{input.text}}`，可以在变量前后编写说明，输入原文仍原样插入。

模板只展开一次。变量内容中的双大括号不会继续当成预设变量执行；角色和世界书原有的 `{{user}}` 名称替换仍然有效。需要书写字面双大括号时，在左括号前加反斜线，例如 `\{{示例}}`；两个连续反斜线表示一个字面反斜线。未知变量或未闭合变量会阻止保存并显示问题位置。

世界书默认只包含激活的条目。会话历史默认包含已有摘要和保留对话；会话状态不再展开为“会话背景”注入模型。会话状态自身的保存、使用和加载条件判断继续有效。世界共享状态也不会自动加入世界书节点。

## 编辑与恢复默认

修改先进入编辑草稿，应用到页面后再保存整个预设。系统节点提供“恢复默认”，读取应用内置的同名节点模板，只替换该节点的提示词；节点位置、启停状态、名称及其他配置保持原样。放弃页面更改会回到上次保存的版本，与恢复内置默认不同。

世界状态、行动建议的开关同时控制提示词注入和对应结果处理，没有会话级覆盖开关。没有激活的可更新状态时，本轮省略整个世界状态节点。

## 历史整理

上下文设置支持滚动摘要或滑动窗口，以及输入和输出预算。完整输入达到输入预算时执行一次整理，目标约为预算的 60%。摘要调用只使用压缩提示词和待整理的聊天历史，已有摘要参与合并；摘要结果作为后续历史的一部分。摘要不执行状态更新或行动建议处理。

删除模板中的摘要变量会让摘要不再进入叙事上下文；使用滚动摘要时应保留有效的摘要引用。上下文组成展示按实际发送的模板文字、摘要、历史和输入归类，重复引用会按实际次数计入。

## 状态与行动建议

模型先完成正文，再按顺序输出启用的 `state_update`、`action_suggestions` 数据块，无外层标签。世界状态只展示可更新状态的当前值和规则；状态更新接受新值，按类型、范围和权限校验。`description` 是给模型的业务规则说明，不是服务端可执行的条件代码。

行动建议固定为缓慢、中速、快速三个方向，每条最多 50 个字符。生成结果仅通过事件送达当前会话，绑定对应故事消息展示；点击填入草稿。下一轮受理后清除，刷新或重进不恢复。断线时禁用，重连核对仍属于最新一轮后恢复可用；错过的建议不补发。

## 保存与导入

保存冲突或失败时保留编辑草稿。导入只接受当前的字符串模板格式；旧版 `prompt.parts` 文件需先使用显式转换工具，常规导入与运行时不自动转换。格式转换保留预设身份和会话引用，数据库转换需在关闭服务、备份数据并取得数据目录锁后显式执行。

可导入示例见 [默认预设](./default.json)；内置初始化与恢复默认的模板位于 `apps/server/resources/presets/default.json`。

# 预设

预设决定一轮故事使用哪些提示词、如何整理历史，以及是否更新世界状态和生成行动建议。会话使用绑定的预设；开始生成后，本轮配置保持不变，后续修改从下一轮生效。

## 提示词节点

固定系统节点依次为：主提示、用户信息、角色信息、世界书、会话历史、用户输入。这六个节点始终启用。主提示可以编辑，自定义文本节点插入在主提示之后。前端可以查看节点的完整提示词模板，并选择会话展开预览；预览不调用模型，也不写入会话。

世界书只包含激活的世界书条目。会话历史包含会话状态说明、已有摘要和保留的对话。世界背景和世界共享状态不会自动加入世界书节点。

世界状态、行动建议是两个默认开启的后置处理节点，放在用户输入之后。开关同时控制提示词注入和对应结果处理，没有会话级覆盖开关。没有激活的可更新状态时，本轮省略整个世界状态节点。

## 历史整理

上下文设置支持滚动摘要或滑动窗口，以及输入和输出预算。完整输入达到输入预算时执行一次整理，目标约为预算的 60%。摘要调用只使用压缩提示词和待整理的聊天历史，已有摘要参与合并；摘要结果作为后续历史的一部分。摘要不执行状态更新或行动建议处理。

## 状态与行动建议

模型先完成正文，再按顺序输出启用的 `state_update`、`action_suggestions` 数据块，无外层标签。世界状态只展示可更新状态的当前值和规则；状态更新接受新值，按类型、范围和权限校验。`description` 是给模型的业务规则说明，不是服务端可执行的条件代码。

行动建议固定为缓慢、中速、快速三个方向，每条最多 50 个字符。生成结果仅通过事件送达当前会话，绑定对应故事消息展示；点击填入草稿。下一轮受理后清除，刷新或重进不恢复。断线时禁用，重连核对仍属于最新一轮后恢复可用；错过的建议不补发。

## 保存与导入

保存冲突或失败时保留编辑草稿。导入只接受当前预设格式，不转换旧格式。可导入示例见 [默认预设](./default.json)；运行时初始化数据位于 `apps/server/resources/presets/default.json`。

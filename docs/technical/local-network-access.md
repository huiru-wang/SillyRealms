# 局域网访问

构建 Web 后运行 `pnpm dev`（Server 也提供构建后的 Web 页面），启动日志会列出本机地址和检测到的非回环 IPv4 局域网地址。访问端口默认为 3000，可用 `PORT` 更改。开发时分别运行 `pnpm dev` 和 `pnpm dev:web`，Vite 将打印 5173 端口的局域网地址，并将 API 请求代理到本机的 3000 端口；5173 已被占用时开发服务器会报错退出。

Server 允许启动时检测到的本机 IPv4 地址对应的 Server 端口和 5173 端口作为浏览器 Origin，其他非本机来源仍被拒绝。网络地址发生变化后需要重启 Server。IPv4 地址可能包含 VPN 或虚拟网络接口，是否可达取决于网络和防火墙配置。

局域网 HTTP 访问没有登录或传输加密；能连接该服务的设备可以访问和操作此实例，包括其世界、会话与模型配置。只应在可信网络中使用。通过 HTTP 地址打开时浏览器可能限制剪贴板等仅限安全上下文的功能。

# StudioV2 管理工作区

## 范围

StudioV2 与 ServerV2 是独立工作区，不切换或修改原 Studio/Server 的启动入口。当前挂载五个管理入口：

| 入口 | 产品能力 |
|---|---|
| 世界卡 | JSON/ZIP 导入、标签分类、分页内容库、静态详情与只读作者预览、名称/标签/默认配置管理、导出/原件下载、受限删除 |
| 预设 | 列表、按需读取详情、创建、复制、编辑、删除、文件导入导出、设为默认；当前仅叙事类型 |
| 模型 | 分页列表、详情、新增、修改、删除、凭据保存状态、设为默认；服务商和模型标识手动输入 |
| 设置 | 主题和应用默认预设/模型，默认项可以清空 |
| 会话 | 从世界详情进入关联列表、创建基础记录、查看详情、修改标题/预设/模型、删除 |

会话创建读取已有世界及可扮演角色，全局会话页和世界详情共用创建弹窗。世界详情只管理名称、标签和默认配置，不提供作者内容编辑器。空 V2 库没有世界时会提示无法创建；不会读取旧 Server 数据或生成模拟世界。创建会话不会执行开场、模型调用、状态规则或消息生成。复制保留的其他功能源文件未挂载，不构成 V2 的运行能力。

## 数据行为

- 世界列表沿用原 Studio 的标题、导入、标签分类与卡片布局；不放常驻搜索表单。按导入时间倒序，标签保留在 URL；摘要不读取作者正文。详情完整沿用原 Studio 的可折叠概览、横向角色条与六个图标 Tab：介绍、世界书、世界状态、开局、会话、运行配置。概览与内容区独立滚动，保留角色条位置同步、键盘操作、开局左右切换、触摸切换、初始状态弹窗、减少动画及移动端尾部留白。开局有作者组件时显示组件，否则显示正文，不执行状态规则。
- 世界管理保存只提交变更字段及 expectedRevision；冲突保留本表单草稿，确认放弃后才重新读取。名称/标签通过概览右上角更多菜单的弹窗编辑；默认配置在“运行配置”Tab 使用原版表单布局。切换章节或离开页面不承诺表单草稿持久化。
- 世界默认可清空，只影响之后会话创建的预填；显式空值不回退到应用默认，弹窗允许本次覆盖且不回写世界。从世界详情创建时，角色在头部角色条选定并带入确认弹窗；当前开局名称仅作展示和会话标题，创建请求不包含 openingId。全局会话页仍在弹窗选择世界与角色。世界与角色创建后只读。
- 导出当前内容与下载导入原件分别操作。存在会话时拒绝删除；数据库已删但文件清理失败时，目录仍显示重试入口。本次工作区内存保留待清理 ID，不提供浏览器重启或进程崩溃恢复保证。
- 预设目录只加载摘要，编辑器进入详情后加载正文；已保存数据与草稿独立，导航保留草稿。保存携带版本，409 冲突保留草稿，可复制或确认放弃后重新读取。温度留空代表不指定，滚动摘要才要求摘要提示词。
- 管理列表可继续加载下一页；选择器读取全部摘要页，避免已有配置在第一页外时丢失。查询切换取消过期请求，错误可重试。
- 设置只提交变化字段。显式清空保存 null，应用默认仅在世界导入时复制，不覆盖已有世界或会话。预设/模型入口设默认后同步全局状态。
- 模型保存 API Key 到 ServerV2 的 macOS Keychain 适配器，业务数据库仅存引用，返回值不包含密钥。编辑留空保留原 Key，更换服务商需提供新 Key。configured 只表示存储中存在，不表示调用成功；不提供模型 catalog 或连接测试。其他平台需要装配自己的 CredentialStore，默认不落地明文。
- 模型凭据与数据库是两个资源；用例提供失败补偿和清理重试，不保证进程崩溃原子性。删除受引用约束，凭据清理失败可重试原删除操作。
- 会话列表沿用原 Studio 的列表结构，无关键词搜索或常驻世界选择器；从世界详情进入时保留 worldId 筛选和返回/查看全部入口。ServerV2 的世界列表仍支持可选 q 名称过滤；会话接口只支持 worldId 筛选，不支持关键词搜索。
- 弹窗关闭恢复触发控件焦点；鼠标/触摸关闭不显示键盘焦点环，键盘关闭保留提示，后续键盘操作恢复正常焦点样式。
- 会话创建使用固定的本次请求 ID；响应丢失后可以读取同 ID 确认结果，避免直接重复创建。世界与角色创建后只读，其他绑定配置可修改。

接口字段与错误码见 [Server V2 HTTP](server-v2-http.md)。模块各自负责存储，跨资源写编排留在 usecases；前端 ManagementData 同步默认设置和列表刷新，PresetStore 负责预设草稿，不引入通用业务状态框架。

## 开发入口

在仓库根目录分别执行：

```sh
pnpm dev:server-v2
pnpm dev:studio-v2
pnpm dev:world-preview-v2
```

ServerV2 默认为 127.0.0.1:3001，数据目录 runtime/server-v2；可配置 SERVER_V2_PORT、SERVER_V2_DATA_ROOT。StudioV2 为 127.0.0.1:5176，/api 代理至 3001，可用 SR_STUDIO_V2_SERVER_URL 覆盖代理地址。V2 数据库只执行已知版本迁移，不复用原 Server 库。

## 作者内容预览与部署

预览入口 `world-component.html` 使用独立来源，默认 `http://127.0.0.1:5177`。`dev:world-preview-v2` 仅用于作者介绍/开局预览；未启动它时管理和静态内容仍可用，组件显示加载错误及重试。它不启动 runtime 或会话 Stage。

`pnpm --filter @sillyrealms/studio-v2 build` 分别构建 `dist`（管理）和 `dist-preview`（预览）。两个目录必须部署在不同来源；不能把预览文档放回管理来源。配置如下：

| 配置 | 用途 |
|---|---|
| VITE_STUDIO_ORIGIN | 预览只信任的宿主来源，默认 http://127.0.0.1:5176 |
| VITE_WORLD_PREVIEW_ORIGIN | 管理页加载预览的来源，默认 http://127.0.0.1:5177 |
| SERVER_V2_STUDIO_ORIGIN | API 接受的 Studio 来源，应与 VITE_STUDIO_ORIGIN 一致 |
| SR_STUDIO_V2_SERVER_URL | 管理页 /api 反向代理地址，预览不配置 API 代理 |

来源必须是无路径/凭据的 HTTP(S) origin；HTTPS 管理页使用 HTTPS 预览。Vite 开发/预览服务隔离 HTML 入口，预览拒绝 /api。生产静态宿主也需保持相同部署边界：只提供对应目录；预览返回 `frame-ancestors <Studio origin>` 响应头，并保留 HTML 内 CSP；管理来源代理 /api，预览来源不代理。

预览 CSP 限制 connect-src/form-action/frame-src/object-src 为 none；脚本只在预览来源执行，图片/音频允许世界资源来源、HTTPS 和许可的数据来源，字体允许世界资源来源。保留 sandbox 与消息来源/窗口/nonce 校验。宿主只接受 world.state.read、global scope，并按请求路径投影 data.item；不暴露完整状态、会话、模型或写 API。世界包资源 CORS 允许素材读取，不开放业务 API 跨域访问。

素材使用 `/api/v1/worlds/:id/resources/`；SDK 将 `sr-asset://assets/...` 转换为保留 assets/ 前缀的资源 URL。组件源码从 /components 按需读取，path 优先，编译缓存按源码内容失效。切换/离开预览销毁 iframe、连接和挂起请求；错误局部展示，可重试。

## 本轮验证边界

只执行函数级测试、TypeScript 类型检查和服务端架构 lint。不启动开发服务、不访问真实凭据、不执行 HTTP、浏览器或模型调用链路测试。前端函数测试覆盖预设转换、世界资源地址、预览来源/权限、状态投影、下载与编译缓存；服务端函数测试覆盖世界摘要/版本/组件读取、导入导出与文件清理、会话身份、状态和数据库迁移。预览配置只做函数加载检查；未执行真实浏览器隔离、视觉或媒体播放验收。

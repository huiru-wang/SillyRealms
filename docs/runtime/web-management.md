# Web 管理工作区

## 范围

Web 通过 HTTP 和 SSE 对接 Server。当前挂载五个管理入口：

| 入口 | 产品能力 |
|---|---|
| 世界卡 | JSON/ZIP 导入、标签分类、分页内容库、静态详情与只读作者预览、名称/标签/默认配置管理、导出/原件下载、确认后删除世界及关联会话 |
| 预设 | 列表、按需读取详情、创建、复制、编辑、删除、文件导入导出、设为默认；当前仅叙事类型 |
| 模型 | 分页列表、详情、新增、修改、删除、凭据保存状态、设为默认；按 provider 选择 SDK 模型并紧凑展示能力参数 |
| 设置 | 中英日界面语言、主题和应用默认预设/模型，默认项可以清空 |
| 会话 | 从世界详情进入关联列表、选择开局并创建会话和首条消息、隔离舞台与叙事运行、修改标题/预设/模型、删除 |

会话创建读取已有世界及可扮演角色，全局会话页和世界详情共用创建弹窗。世界详情只管理名称、标签和默认配置，不提供作者内容编辑器。空 V2 库没有世界时会提示无法创建；不会读取旧 Server 数据或生成模拟世界。创建请求提交 openingId，由 Server 原子保存会话、初始状态及替换 {{user}} 后的首条 assistant 消息，不调用模型或执行作者组件。创建成功进入会话运行页；发送、停止、历史、状态和行动建议使用 Server 契约，见 [会话运行接入](web-runtime.md)。

## 数据行为

- 世界书条目收起时，仅在 `load.when` 引用了状态时标注“状态关联”。展开后先列出关联状态（按作用域与路径去重）、再显示原始表达式，最后显示正文；无 `when` 时直接显示正文。未指定作用域标为“自动查找”，不展示会话状态值或推断当前是否命中。

- 预设节点的变量帮助区分整域说明（如 `{{state.session}}`）与只读字段（如 `{{state.session.人设.姓名}}`）。合法但未加载或不存在的字段运行时留空；压缩提示词不是变量模板。

- 开局初始状态弹窗只显示 message 的有效初始值：开局 initial_state 按根完整替换世界默认，不合并子字段、不补规则中预声明的字段。根节点标记“开局设定／世界默认”，默认全部收起；非空对象和数组按需逐级展开，具体字段使用同排的 key/value 两列，长值在右列换行。数组展示真实元素及其序号，每次增加 20 项；空集合直接显示空态，null、空文本、布尔与零值分别保留明确含义。长文本可展开全文。移动端深层导航复用 StateBrowser，在同一弹窗正文中切换并恢复返回位置、焦点、展开及分页状态；不叠加弹窗。帮助信息通过 info 按钮显示，Escape 优先关闭帮助。此值浏览器与世界状态的规则说明树分别投影，共用导航与主题样式。
- 世界状态 Tab 只读展示状态说明，按 global/session/message 排序并省略空分组；分组使用语义背景区分，帮助文案通过 info 按钮显示。非 JSON 根显示 key 与 description；JSON 容器默认全部收起，显示名称与展开入口，叶子显示对应 rules 路径的原文，不展示默认值或加载条件。每个状态名后显示类型标签：根使用声明类型，子字段使用初始值类型；数组元素类型不一致标为“混合类型”，没有初始样本的字段标为“未指定”。说明树结合 rules 路径与 initial 结构生成，保留 null/空数组下预声明的字段；数组只展示一份 `[]` 元素模板，不枚举实际值，不执行规则或生成解释。空容器或标量 JSON 根展开后显示根规则；未提供根规则时使用根 description，子字段未提供说明时留空。移动端最多两级缩进，更深容器进入当前内容区的子层详情，返回恢复展开状态、焦点及内容区滚动位置；桌面继续逐级展开。开局初始状态弹窗独立展示实际初始值及覆盖来源。
- 世界列表沿用原 Web 的标题、导入、标签分类与卡片布局；不放常驻搜索表单。按导入时间倒序，标签保留在 URL；摘要不读取作者正文。详情完整沿用原 Web 的可折叠概览、横向角色条与六个图标 Tab：介绍、世界书、世界状态、开局、会话、运行配置。概览与内容区独立滚动，保留角色条位置同步、键盘操作、开局左右切换、触摸切换、初始状态弹窗、减少动画及移动端尾部留白。开局有作者组件时显示组件，否则显示正文，不执行状态规则。
- 世界管理保存只提交变更字段及 expectedRevision；冲突保留本表单草稿，确认放弃后才重新读取。名称/标签通过概览右上角更多菜单的弹窗编辑；默认配置在“运行配置”Tab 使用原版表单布局。切换章节或离开页面不承诺表单草稿持久化。
- 世界默认可清空，只影响之后会话创建的预填；显式空值不回退到应用默认，弹窗允许本次覆盖且不回写世界。从世界详情创建时，角色在头部角色条选定并带入确认弹窗；当前开局 ID 一并提交，名称作为会话标题。全局会话页在弹窗选择世界、开局与角色；仅有一个开局时默认选中，多个时要求明确选择。缺失的原选择不静默换成其他角色或开局。世界与角色创建后只读。两个创建入口共用简洁配置表单，不提供预设／模型管理跳转或常驻刷新目录按钮。
- 导出当前内容与下载导入原件分别操作。删除世界先发送普通 DELETE；有关联会话时，在同一弹窗显示服务端返回的会话数量及一并删除会话、消息的提醒，按钮变为“删除世界及会话”。用户再次确认才携带 deleteSessions=true；关闭、重新打开或切换世界会重置关联删除确认。成功删除后同时刷新世界与会话列表；数据库已删但文件清理失败时也刷新列表，目录仍显示重试入口。本次工作区内存保留待清理 ID，不提供浏览器重启或进程崩溃恢复保证。
- 预设目录只加载摘要，编辑器进入详情后加载正文；已保存数据与草稿独立，导航保留草稿。保存携带版本，409 冲突保留草稿，可复制或确认放弃后重新读取。温度、Top P、频率惩罚和存在惩罚各自可选择模型默认或自定义，恢复默认清除该键，滚动摘要才要求摘要提示词。
- 管理列表可继续加载下一页；选择器读取全部摘要页，避免已有配置在第一页外时丢失。查询切换取消过期请求，错误可重试。
- 设置只提交变化字段。显式清空保存 null，应用默认仅在世界导入时复制，不覆盖已有世界或会话。预设/模型入口设默认后同步全局状态。
- 模型保存 API Key 到 Server 的 macOS Keychain 适配器，业务数据库仅存引用，返回值不包含密钥。编辑留空保留原 Key，更换服务商需提供新 Key。configured 只表示存储中存在，不表示调用成功。模型目录来自 Server 的 pi SDK；已保存模型配置可由用户显式点击测试连接；检测使用服务端保存的配置，不使用未保存草稿。其他平台需要装配自己的 CredentialStore，默认不落地明文。
- 模型详情顶部操作依次为测试连接、默认、编辑、删除，窄屏标题可单独成行，四个操作保持单行；编辑／删除使用有名称的图标按钮。默认项显示“当前默认”；连通性结果直接显示在测试按钮，不另展耗时、用量或连接详情面板。
- 预设模型参数支持思考开关及可选标准思考深度，默认项不指定档位；显式选择在实际模型支持时使用，不支持所选级别时使用默认深度，关闭思考时深度不生效。
- 模型目录从 `/api/v1/providers/models` 读取 provider 分组；添加/编辑先选服务商，再选该组模型，切服务商清空模型，名称与 API Key 仍由用户填写。目录加载与重试不自动覆盖草稿；已有配置不在当前 SDK 目录中时显示保留项，不自动替换 ID。
- 模型选择后在紧凑参数区显示上下文窗口、最大输出、推理能力、有效思考档位、协议、输入模态及缓存短/长保留时长；详情复用同一参数展示。可用思考级别直接读取 SDK 计算的 thinkingLevels，不展示底层 thinkingLevelMap 映射；缓存单位秒转为可读时长，缺失显示未提供。缓存值是 SDK 最佳估计，不等于当前调用策略或供应商保证。
- 不再包含初始化向导页面、入口、专属加载 Hook 或样式，也不根据是否配置默认模型/API Key 阻止访问管理页。首次启动提供「标准叙事」和「小饭馆」。服务端每次按发行清单的固定 ID 补齐缺失的预设、设置和世界，保留已有用户修改与默认选择（包括 null）。手动导入的同名世界保留各自的会话；删除内置世界后，下次启动会重新安装原始世界。没有模型时用户在模型页自行添加。
- 模型凭据与数据库是两个资源；用例提供失败补偿和清理重试，不保证进程崩溃原子性。删除受引用约束，凭据清理失败可重试原删除操作。
- 会话列表沿用原 Web 的列表结构，无关键词搜索或常驻世界选择器；从世界详情进入时保留 worldId 筛选和返回/查看全部入口。Server 的世界列表仍支持可选 q 名称过滤；会话接口只支持 worldId 筛选，不支持关键词搜索。
- 弹窗关闭恢复触发控件焦点；鼠标/触摸关闭不显示键盘焦点环，键盘关闭保留提示，后续键盘操作恢复正常焦点样式。
- 会话创建使用固定的本次请求 ID；响应丢失后可以读取同 ID 确认结果，避免直接重复创建。世界与角色创建后只读，其他绑定配置可修改。

接口字段与错误码见 [Server HTTP](server-http.md)。模块各自负责存储，跨资源写编排留在 usecases；前端 ManagementData 同步默认设置和列表刷新，PresetStore 负责预设草稿，不引入通用业务状态框架。

## 界面语言设置

应用使用 `zh-CN`（简体中文）、`en`（English）和 `ja`（日本語），默认简体中文。`AppSettings.locale` 是唯一持久化语言来源，经 `GET/PATCH /api/v1/app-settings` 读取和修改；范围是当前服务端应用实例，所有会话共用，不是世界卡、预设或会话的独立配置。前端不把语言写入 localStorage，也不根据浏览器语言覆盖服务端设置；其他浏览器读取设置时采用同一个已保存值，不新增语言推送通道。

`ManagementData` 在读取设置后应用语言并更新文档 lang。语言选择单独立即提交 `{locale}`，收到服务端成功响应后才切换界面；失败保留原选择并显示可重试错误，重复提交期间禁用语言操作。默认预设/模型的基线与草稿只包含各自字段，切换语言不保存或丢弃未提交的默认项草稿，保存默认项也不覆盖 locale。

平台导航、管理表单、空态、加载提示、辅助说明、确认弹窗与错误消息通过 i18n 资源呈现。API 错误保留稳定错误码，在展示时按当前语言映射；已有错误随语言切换更新。数字和日期采用当前语言格式。用户命名、世界/角色正文、世界书、状态路径与取值、用户编辑的预设名称及提示词保持原文，不执行自动翻译。

预设变量帮助提供 `{{system.language}}`，服务端将其展开为 `简体中文`、`English` 或 `日本語`。新建默认预设的 main 带输出语言要求；已有预设不被覆盖，需在相关提示词插入该变量或恢复 main 默认内容才会跟随。摘要提示词沿用原有直接使用方式，不新增变量展开。

宿主把已确认语言随现有受限外观消息传入会话舞台和作者预览。语言变化更新官方展示文本，保留 iframe、MessagePort、预览缓存和作者组件状态，不以语言作为组件重建的 key。作者内容的语言仍由作者控制，隔离权限不因国际化扩大。

## 作者内容预览与部署

预览入口 `world-component.html` 使用独立来源，本地运行时使用主站的主机名和 5177 端口。`pnpm dev:stage` 提供作者介绍/开局预览及隔离的 frame.html 舞台文档；未启动它时管理和静态内容仍可用，组件显示加载错误及重试。会话页使用独立 frame.html；舞台重建不销毁会话业务控制器。

`pnpm --filter @sillyrealms/web build` 分别构建 `dist`（管理）和 `dist-preview`（world-component.html 与 frame.html 隔离文档）。两个目录必须部署在不同来源；不能把预览文档放回管理来源。配置如下：

| 配置 | 用途 |
|---|---|
| VITE_WEB_ORIGIN | 固定预览信任的宿主来源。本地默认使用舞台所在主机的 5176 端口 |
| VITE_WORLD_PREVIEW_ORIGIN | 固定管理页加载预览的来源。本地默认使用主站所在主机的 5177 端口 |
| SERVER_STAGE_ORIGIN | runtime/config 对外返回的舞台 origin，外部部署时与隔离部署地址一致 |
| SERVER_DEBUG | true 时 runtime/config 返回 debug:true，默认 false |
| SERVER_WEB_ORIGIN | API 接受的 Web 来源，应与 VITE_WEB_ORIGIN 一致 |
| SR_WEB_SERVER_URL | 管理页 /api 反向代理地址，预览不配置 API 代理 |

来源必须是无路径/凭据的 HTTP(S) origin；HTTPS 管理页使用 HTTPS 预览。Vite 开发/预览服务隔离 HTML 入口，预览拒绝 /api。独立静态部署在构建时指定 VITE_WEB_ORIGIN 和 VITE_WORLD_PREVIEW_ORIGIN，并在服务端指定对应来源。生产静态宿主也需保持相同部署边界：只提供对应目录；预览返回 `frame-ancestors <Web origin>` 响应头，并保留 HTML 内 CSP；管理来源代理 /api，预览来源不代理。

预览 CSP 限制 connect-src/form-action/frame-src/object-src 为 none；脚本只在预览来源执行，图片/音频允许世界资源来源、HTTPS 和许可的数据来源，字体允许世界资源来源。保留 sandbox 与消息来源/窗口/nonce 校验。宿主只接受 world.state.read、global scope，并按请求路径投影 data.item；不暴露完整状态、会话、模型或写 API。世界包资源 CORS 允许素材读取，不开放业务 API 跨域访问。

素材使用 `/api/v1/worlds/:id/resources/`；SDK 将 `sr-asset://assets/...` 转换为保留 assets/ 前缀的资源 URL。组件源码从 /components 按需读取，path 优先，当前详情共享源码请求及结果，编译缓存按源码内容失效。详情内最多保留 10 个作者组件预览实例（介绍及各开局独立计数），超出时按首次打开顺序淘汰；重访不调整顺序。切换 Tab/开局仅隐藏缓存实例，保留交互状态和当前开局选择；淘汰、重试或离开详情才销毁对应 iframe、连接和状态请求。离开详情同时取消共享源码请求。管理字段更新不重建预览，组件声明变化会重建。隐藏时暂停 HTML 音视频和 CSS 动画，不承诺暂停作者计时器或 Web Audio；音视频不会在切回时自动播放。错误局部展示，重试刷新源码并只重建该实例。完整缓存与状态新鲜度约束见[世界组件](../design/world-components.md#详情切换与缓存)。

## 本轮验证边界

只执行函数级测试、TypeScript 类型检查和服务端架构 lint。不启动开发服务、不访问真实凭据、不执行 HTTP、浏览器或模型调用链路测试。前端函数测试覆盖预设转换、世界资源地址、预览来源/权限、状态投影、下载与编译缓存；服务端函数测试覆盖世界摘要/版本/组件读取、导入导出与文件清理、会话身份、状态和数据库迁移。预览配置只做函数加载检查；未执行真实浏览器隔离、视觉或媒体播放验收。

Server 的 `/api/v1/runtime/config` 使用 `{stage:{origin,entryPath},debug}`，不再传单独 port。Web stageURL 按完整 origin 构造 frame.html，校验隔离与 HTTPS，并保留 hostOrigin/nonce。Vite 的 world-preview 模式开放 frame.html/world-component.html 并一同打入 dist-preview，禁止 API 代理；管理模式拒绝这两个 HTML 入口。会话页现已通过独立 features 与受限桥接入叙事、state 和查询契约；源码/函数验证不替代真实模型与浏览器验收。

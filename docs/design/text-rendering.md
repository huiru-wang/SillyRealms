# 文本渲染与转换

> **MVP 状态说明**：本文保留原有目标设计；若与本次 Server MVP 的已调整范围或实际行为冲突，以 [Server MVP 实施进度](../technical/server-mvp-progress.md)及其中链接的方案为准。文中的未来功能不代表已实现。

> **职责与权威范围**：文本模板、literal 边界、输出转义及场景文本转换的权威来源；脚本 API 与加载选择以各自规范为准。

> 2026-11-05 目标设计，尚未实现。SR 采用 JavaScript + EJS；状态与变量 API、生命周期和执行隔离见[脚本与状态 API](script-runtime.md)，条目选择见[内容加载判断](content-activation.md)。

TextRenderer 负责解析并执行已激活内容的 EJS，支持标准 `<% ... %>`、`<%= ... %>` 和 `<%- ... %>`；其中 `<%=` 按 EJS HTML 转义，`<%-` 原样输出。Prompt 纯文本中不需要 HTML 转义时明确使用 `<%-`；UI 显示必须根据输出目标安全渲染。EJS 版本、输出规则和可用 JavaScript 特性须固定并验证。`{{user}}` 等原有普通宏是否保留由宏规范处理；旧 `{{state:/...}}`、自定义 `{{#if ...}}` 不再作为状态语法。

模板上下文提供 `getState` 和 Run 级 `getvar/setvar`；普通 Prompt 脚本可通过 `setState` 更新本轮工作状态，不直接持久化；后续脚本立即读到新值。示例：

```ejs
<% const 心情 = getState('清月.心情', {scope: 'message'}); %>
<% setvar('本轮心情', 心情); %>
清月的心情：<%- 心情 %>
```

世界书条目、角色描述和预设模板分别执行，每段有自己的局部作用域，Run 变量按确定顺序共享；完整规则见脚本文档。读取 Global 状态渲染世界卡首页时，不创建会话；访问不存在的 Session/Message 状态报诊断。模板结果是数据，不再次执行为模板。

TextTransform 独立负责按 `prompt/preview/ui` 场景执行明确配置的文本替换和正则；模板之前内容激活，激活后按节点顺序渲染，随后按场景转换并与 literal 拼接。当前 User 和历史正文不执行模板或因模板处理而被隐式改变。不可提供动态读取/激活世界书的 `getwi/activewi`。

导入的 EJS/JS 由隔离执行环境运行，语言版本、宿主 API、权限、超时、内存和输出限制须先固定并验证；不直接将外部脚本交给应用服务进程执行。模板失败返回来源定位诊断，不悄悄发送半渲染文本；预览使用隔离工作状态及临时变量，允许模拟脚本 setState 且结束丢弃，不得持久化。验证同输入同结果、局部变量隔离、Run 共享与销毁、不同场景转换、工作状态顺序及错误处理。

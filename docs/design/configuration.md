# 配置：预设、Provider 与模型连接

> 状态：领域设计，2026-11-01；存储和 API 细节另见[存储](../technical/storage.md)。返回[文档索引](../README.md)。

## 配置边界

- **预设（Preset）**负责可复用的生成行为：选用模型连接、上下文长度、温度、Top P、存在惩罚、续写/帮答指令、自建提示词条目与 Prompt 组装顺序等。Prompt 注入及命中逻辑由[Context](context.md)统一解释。
- **Provider / API 连接**负责模型服务、平台、服务地址、模型 ID 与凭据；预设只引用连接，不复制密钥。模型可以由用户选择，平台是否提供该模型及支持何种参数需以实际调用结果为准。
- **世界卡**只存世界定义，不内嵌用户 API 凭据；**世界实例**引用预设并保留世界内容快照，实例内的故事与分支不因预设修改而回写。

## 预设的生效方式

每份预设只维护**一份当前配置**；不设计版本历史，也不对实例做预设版本同步。每次生成读取该预设的当前值；生成过程中更改预设仅影响**下一次**执行，不修改已产生的文本。预设可创建、编辑、导入与导出；不含 API Key。

实例是否允许单独覆盖预设参数、覆盖优先级、冲突时 UI 表现、缺失预设的处理方式，留待实现前确定，不在本阶段先建第二套配置来源。

## 模型连接与安全

- 创建连接时填写名称、选择平台、配置 API 地址和凭据，并选择或直接输入模型 ID。可以根据项目配置或内置清单展示候选模型，**不宣称清单实时或完整**。
- 一个连接选择一个模型；同一平台需要不同模型或凭据时，创建独立连接即可。预设引用 `api_connection_id`，连接负责实际模型选择。
- 删除被预设引用的连接时必须先提醒并要求解除或重新选择；模型 ID 暂不可用时可以保存供修改，但调用失败必须明确提示，不自动替换为其他模型。
- 凭据由本地服务安全管理，普通配置、消息、世界卡及导出均不保存或展示明文 API Key。密钥存储方式与局域网开放的安全边界需在实现前验证。

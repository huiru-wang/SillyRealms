## 冲突裁决（当前第一轮实验，非最终规范）

| 项目 | 当前 Studio 决策 |
| --- | --- |
| 视觉主基准 | 展开图：整体品牌、背景、信息层级依据 |
| 收起结构 | 收起图：图标竖栏与底部操作、主区扩展 |
| 全局顶栏 | 不存在；标题/导入是内容区的一部分 |
| 字体 | 系统无衬线中文/英文统一栈，不复制 AI 图中不一致的字体 |
| 色彩 | 低饱和石墨紫 Dark 主调，Color Lab 后续可调，非锁定 |
| 侧栏 | 展开 280px / 收起 64px，同一浮动容器，距视口边缘始终 14px；布局轨道为 308px / 92px |
| 背景层次 | 主内容微弱环境光、侧栏更深，不堆发光 |
| 分类 | 选中状态为低对比紫灰底色；选中 + Hover 不重复上色 |
| 卡片 | 图片主导、细边框、下渐变遮罩、底部文字元信息 |
| 操作入口 | 导入在内容区右上；设置 / 主题 / 侧栏折叠在 Sidebar 底部纵向对齐 |
| 移动端 | 左侧 Drawer，2 列卡片，横向可滚分类 |

## 第二轮交互规范验证（2026-11-10）

本轮解决：侧栏展开/收起风格不一致、过渡中断、Selected 项重复 Hover 变色。

1. **稳定形态**：展开/收起为同一个侧栏 DOM 容器，不再切换背景、圆角、边框或浮动/贴边定位；视口边距与图标基准位置保持不变。
2. **连续布局**：Sidebar 轨道通过 `grid-template-columns` 在 270ms 内插值，世界卡页 padding 和分类 gap 使用相同缓动。缓动为 `cubic-bezier(.4,0,.2,1)`，不添加弹跳。
3. **内容过渡**：Logo、导航和底部标签、会话/预设列表在收起时先淡出，展开时延迟淡入；这些元素不因侧栏切换被 React 卸载。收起时隐藏列表使用 `inert` 和 `aria-hidden`。
4. **状态优先级**：Selected + Hover 与 Selected 保持相同背景。Hover 仅适用于未选中项；键盘焦点保留独立轮廓，触摸设备不遗留粘滞 Hover。
5. **弹层动画**：Dialog 使用 200ms 透明度和微小垂直位移进出；支持 Escape、点击遮罩退出与 reduced-motion。
6. **移动端边界**：桌面保存的 collapsed 偏好不应隐藏手机 Drawer 中的文字/列表；手机仍展示完整导航内容。
7. **回归证据**：Studio 类型检查、生产构建、旧 Web 类型检查和 Chrome CDP 测试；CSS grid 过渡在固定时间的中间帧断言宽度单调变化、容器材质不变；检查选中状态、主题、分类、弹窗与移动端。

这是已实现的**交互约束**，不代表整体首页视觉基调已经最终获批。

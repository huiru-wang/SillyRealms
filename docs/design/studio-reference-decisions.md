## 第二轮交互规范验证（2026-11-10）

本轮解决：侧栏展开/收起风格不一致、过渡中断、Selected 项重复 Hover 变色。

1. **稳定形态**：展开/收起为同一个侧栏 DOM 容器，不再切换背景、圆角、边框或浮动/贴边定位；视口边距与图标基准位置保持不变。
2. **连续布局**：Sidebar 轨道通过 `grid-template-columns` 在 270ms 内插值，世界卡页 padding 和分类 gap 使用相同缓动。缓动为 `cubic-bezier(.4,0,.2,1)`，不添加弹跳。
3. **内容过渡**：Logo、导航和底部标签、会话/预设列表在收起时先淡出，展开时延迟淡入；这些元素不因侧栏切换被 React 卸载。收起时隐藏列表使用 `inert` 和 `aria-hidden`。
4. **状态优先级**：Selected + Hover 与 Selected 保持相同背景。Hover 仅适用于未选中项；键盘焦点保留独立轮廓，触摸设备不遗留粘滞 Hover。
5. **弹层动画**：Dialog 使用 200ms 透明度和微小垂直位移进出；支持 Escape、点击遮罩退出与 reduced-motion。
6. **移动端边界**：桌面保存的 collapsed 偏好不应隐藏手机 Drawer 中的文字/列表；手机仍展示完整导航内容。
7. **回归证据**：Studio 类型检查、生产构建、旧 Web 类型检查和 Chrome CDP 测试；CSS grid 过渡在固定时间的中间帧断言宽度单调变化、容器材质不变；检查选中状态、主题、分类、弹窗与移动端。

这是已实现的**交互约束**，不代表整体首页视觉基调已经最终获批。

## 侧栏导航调整（2026-11-10）

- 顶部主导航只保留世界卡；会话列表、预设列表标题分别链接到 `/sessions`、`/presets`，下方快捷项保留。当前目的页仍为静态占位。
- 桌面收起时以带可访问名称的图标提供两个列表入口；移动端抽屉显示完整标题和快捷项。底部依次为设置、主题、模型、收起侧栏，模型链接至 `/models`。
- 会话封面为 44 × 44px，保留原有行的最小高度；导航选中态优先于 hover，沿用既有侧栏与布局过渡。

## 首页交互与侧栏一致性优化（2026-11-11）

- 展开侧栏的主导航、可点击分组标题、会话、预设和底部操作使用统一的左右交互边界；内容可按类型缩进，行高保留差异。未选中的项目使用一致的悬浮背景，选中态优先；预设不再使用常驻底色。
- 移除会话行上没有独立操作的省略号，避免暗示存在更多菜单。
- 世界卡筛选增加默认的「全部」选项，保留原有筛选；无结果时可直接返回全部。筛选按钮通过按下状态表达当前选择。
- 移动端扩大导航、导入和筛选的触控区域，并提高卡片次级文字字号。弹窗打开时后台不可交互，Tab 在弹窗内循环，关闭后恢复焦点。
- 这些调整仍属于静态设计探索；封面原图、复杂页面和整体视觉基准仍待后续验证与用户确认。

## 侧栏一级入口与连续过渡（2026-11-11）

- 世界卡、会话列表和预设列表使用相同的一级导航字号、字重、图标和选中/悬浮规则；会话与预设快捷项使用较小的次级文字。
- 会话和预设入口在展开与收起时共用同一图标与链接。收起时快捷项淡出并压缩高度，入口随布局连续移动；移动端抽屉始终恢复完整内容，减少动态效果设置继续生效。

## 世界卡详情页静态原型（2026-11-11）

- 新增路由 `/worlds/:worldId`，世界卡列表点击进入独立详情页，不再使用详情弹窗。仅使用本地 fixture。
- 保留 Studio AppShell 和语义 tokens，世界概览展示封面、名称、简介、标签及所有角色；下方为介绍、世界书、世界状态、开局、运行配置五个章节。
- 滚动机制：世界概览正常纵向滚动；紧凑头部进入阅读区后 sticky，左侧保留封面及世界名，右侧才渐显**所有角色**的横向滚动列表。概览下方角色列表先淡出，不将单个角色卡做位移动画。
- 两组列表共享选择状态并双向同步横向滚动位置；未显示的紧凑列表为 inert，不截获纵向滚轮。
- 移动端紧凑头部采用上下两行，世界身份与全部角色分别排列；内容章节转为可横向滚动导航。
- 测试：Studio typecheck/build 和 CDP visual 测试覆盖详情展开/收敛、角色选择、章节切换及移动端截图。截图仍属本地探索版本，不自动作为 Golden。

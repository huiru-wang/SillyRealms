# 决策：平台输入区与可组合的 WorldStory

平台持有会话输入区和草稿，作者控制隔离 iframe 的故事内容区。默认界面和作者页面使用同一个系统 `SR.WorldStory`，且作者可在自定义页面中组合它与其他组件。消息展示规则只改变显示；多个消息组件共享一个源码模块并通过注册名称引用。组件行为使用公开 SDK，状态和 Run 仍以 Server 为权威。

原因：在保留作者布局及玩法自由度的同时，为用户提供稳定的发送、停止和会话设置入口，并避免每个世界重复实现历史、流式消息及规则处理。正则匹配委托可信 Host 所持有的隔离 Worker，作者源代码仍只在 iframe 运行。

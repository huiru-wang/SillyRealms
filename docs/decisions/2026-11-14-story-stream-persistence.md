# 正文结束保存与快照恢复

用户明确选择正文在生成结束后持久化，继续优化主叙事 `SR.WorldStory`。

- 每条模型响应的正文只在完成时写入；停止/失败也保存已确认正文。Direct 为单次响应，Agent 保留各响应结束后的原始模型/工具记录。
- 生成期间用内存正文快照与稳定 messageId 服务刷新/重连，SSE delta 携带 UTF-16 offset。Server 进程退出可能丢失尚未结束的正文，接受这一取舍。
- 接受输入、摘要、Usage journal 和状态提交规则不变。正文增量是临时预览；状态/Run 终态仍在持久化后通知。
- 历史页、恢复快照和实时片段共用前端合并规则；位置去重、缺口补查、终态校准。没有持久事件重放。
- WorldStory 批量刷新活跃正文、缓存历史渲染并保留 DOM/Portal 身份；保留阅读锚点和底部跟随。暂不引入虚拟列表或新 Markdown 引擎。

这是对此前“所有正文事件都先落库”规则的明确调整，不需要数据库迁移，不改变作者 iframe 隔离边界。

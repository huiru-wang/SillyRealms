# 世界卡制作经验

## 在角色与世界书中引用状态

角色提示词和已激活的世界书正文可直接写 `{{state.session.人设.姓名}}`。例如，台词提示是“你叫{{state.session.人设.姓名}}，还有{{state.message.银两}}两银子”，姓名为“沈青”、银两为 0 时，模型看到“你叫沈青，还有0两银子”。世界卡导入保留原文，下一轮读取下一轮的状态，不改写卡或历史。

可以读取 global、session、message 已加载的状态根或其对象字段；对象和数组整体显示为 JSON，不支持数组下标。无效状态路径、字段未加载或不存在时只留空；未知自定义占位如 `{{ weather.today }}` 原样保留。即使姓名的值本身是 `{{user}}`，也只显示这段文字，不会再次替换。整组占位 `{{state.session}}` 是预设变量，不能用于在世界书中注入整域状态。

## 玩家人设、建角资料与世界书的归属

转换酒馆角色卡时，先判断一段内容描述谁、由谁填写、何时会变。原卡可能把玩家人设写在世界书里，供建角脚本改写。迁入 SillyRealms 后，固定身份写入可扮演角色的 `characters[].prompt`，选中该角色时由服务端纳入 `persona.prompt`。[上下文素材选择实现](../apps/server/src/usecases/context/stages/materials/index.ts)

| 内容 | 制作时放在哪里 | 黎安卡举例 |
| --- | --- | --- |
| 每次选择该角色都成立的身份与身世 | 可扮演角色定义 | 玩家是“仇”组织天榜第三，十年前藏身井中逃过灭门。 |
| 建角题目、选项及其含义 | 建角资料，供收集答案时使用 | “这些年”五问中，“你攒下最多的是……”有四个选项，其中“钱”对应“你颇有家资”。 |
| 玩家填写的资料与已选结果 | 开局写入 session 状态，预设用 `{{state.session}}` 读取本轮加载的人设。游玩中会变化的字段另存 message 状态 | 自填姓名、民间身份、性格，以及玩家实际选出的“你颇有家资”。 |
| 随剧情发展的事实 | 消息状态，按剧情依据更新 | 玩家当前年龄、地点、修为、武学和随身物品。 |
| 多个角色共处的世界设定 | 世界书，按题材常驻或按需加载 | “仇”的来历、天榜制度、大顺朝廷与江湖的关系。 |

**验收例子**：用两个新局，在第一局选“钱”，第二局选“并没有攒下什么”。检查下一轮模型输入：第一局应有“你颇有家资”，第二局按原卡映射不追加人设词。两局的日常叙事都不应载入整份题库，选择“钱”也不应直接增加物品栏里的银两。[原卡五问与答案映射](../resources/silly-tavern/灭仇家满门之后，我收养了想对我复仇的孤女/开局状态与地图速查.md)

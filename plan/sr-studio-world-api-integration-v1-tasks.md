## 关键验证

- 接口：标准成功/失败信封，世界标签 ID 与详情标签名的差异、排序及 cursor 查询签名，404、坏世界、离线、无响应、错误页重试。
- 异步：快速切换筛选和世界、连续加载更多、组件卸载后过期响应不得覆盖当前界面；列表筛选失败不得展示 fixture 或“无数据”。
- 正文与安全：富文本混排及长文、危险标签/属性/链接/样式清理、隔离文档的布局和主题；开局预览与正式会话消息保持语义区别。
- 交互：展开/收敛、正文滚动、角色横向锚点、键盘焦点、无障碍状态、用户所需的开局左右切换，以及世界会话列表的加载、分页和错误状态。
- 环境：Vite 5174 代理到明确的 3000 服务；测试回环地址的 Origin，LAN 若被纳入范围则以具体来源单独验证；生产托管不在本阶段假设。
- 命令：`pnpm --filter @sillyrealms/studio typecheck`、`pnpm --filter @sillyrealms/studio build`、`pnpm --filter @sillyrealms/studio test:visual`，以及针对实际改动的 Server 测试；不把根脚本误当成覆盖所有项目。

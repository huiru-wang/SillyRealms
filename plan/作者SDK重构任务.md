# 世界组件与舞台 SDK 重构任务

以下任务对应[全局 SDK 目标方案](作者SDK重构方案.md)，均为实施与验收清单。本次规划更新不代表接口已发布。

| 顺序 | 实施任务 | 可验证的完成条件 |
|---|---|---|
| 1 | 盘点 SDK 根导出、两种 frame 注入、编译器、官方组件、示例和内置包。记录旧卡版本与既有副本的迁移选择。 | 每个旧入口有替代能力或退出说明；能够定位受影响世界，不覆写用户副本。 |
| 2 | 迁移 Host 到 state/query 与 state/update。保留现有调用者的可用路径，分开整域与指定字段缓存。 | 三种 scope、消息继承、零值、null、缺失和重复路径均正确。查询一个字段不会清掉兄弟字段；详情仅发送当前世界的指定 global 路径。 |
| 3 | 贯通状态 outcome、tip 前置条件、结构化错误和批次顺序，接入 useSRState 与 StateAPI 四个方法。 | changed/unchanged/missing 来自提交边界；模型写入授权不变；按消息执行身份隔离，同值/缺失不落库，旧 tip 写入拒绝。批次预检、部分成功、回执丢失、写后回读失败可分别验证。 |
| 4 | 在现有会话通道上投影目标 SREvent。实现按名订阅、解除和 frame 生命周期清理。 | 覆盖清单内每个事件。检查 append/replace（含同帧定稿及空正文）、纯推理分片、重生成 ID、取消订阅及监听器异常。私有数据在发往 frame 前裁剪。 |
| 5 | 对齐会话选择器、独立历史查询和历史失效通知。 | 两个阅读器独立分页；首读/翻页期间发生删除、终态更新或重连时能丢弃过期页；中途挂载可获得已有活动正文。HTTP 和 SSE 的先后顺序不产生重复消息。 |
| 6 | 迁移官方阅读器、状态面板、行动区、静态内容和预览，接入资源与舞台按钮。 | 与自定义组件使用相同 SDK 业务入口。只观察状态的组件不因 token 增量重渲染；打开状态面板可复用已确认数据；建议为空无布局占位，端口与按钮版本交错不会误触。 |
| 7 | 对齐类型、根导出、环境注入、制卡检查和实例。按盘点结果迁移作品与公开手册。 | 校验间接依赖及挂载环境；详情拒绝整域、写入及会话事件。官方、作者与消息组件示例可通过编译，替换组与布局正确。 |
| 8 | 运行静态、函数与集成验证，记录旧卡策略和发行影响。 | 分开报告类型、lint、构建、制卡静态校验、实际导入和游玩。服务端函数验收遵守仓库关于不启动真实服务的约束。 |

实施阶段使用仓库的 typecheck、lint、build、Web、Server 函数及 world-card 测试命令。对受影响的世界源码和最终 ZIP 分别运行 world:check。静态检查通过后，实际导入与游玩仍需各自的验证记录。

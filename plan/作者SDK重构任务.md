## 最少回归场景

- **游标与竞态。** 首次查询期间发生提交；旧页慢于重连后的新首页返回；同一轮重新生成产生新的助手消息 ID；纯 delta 不触发持久化失效；只更新终态也会通知。监听器解除后不再收到回调。
- **状态与上下文。** 详情修改世界天气，会话读取同一实际值；查询顺序稳定，包含缺失路径和显式 null；空查询只写不读；可读取完整 message 账册；跨 scope 批写逐项可判别；同一世界活动执行时 global 锁有效；旧 frame 退出或重试后不再操作新绑定的目标。
- **作者扩展。** 原始草稿可编辑，直接发送只确认受理；建议为空时整块消失；按钮版本更替后旧点击失效；消息匹配的分组、身份和 inline/block 展示保留。
- **公共面。** 实际导出与类型一致；不存在的导入、未经支持的宿主工具导入能在制卡阶段定位；已保存查询结果只包含承诺字段。

## 验证命令与结果记录

在实施分支运行 `pnpm typecheck`、`pnpm lint`、`pnpm test:web`、`pnpm --filter @sillyrealms/server test` 和 `pnpm test:world-cards`。分别用 `pnpm world:check examples/worlds/fog-harbor` 和 `pnpm world:check initial-data/worlds/小饭馆.zip` 验证示例源码和最终发布包。

上述命令属于静态或函数级验证。实际导入和游玩分别列项记录；当前规划阶段未执行。集成验证依仓库约定在函数级、类型与 lint 层面完成，不为本方案另起服务或建立模拟端到端环境。

## 1. 任务拆分

| 任务 | 依赖 | 范围 | 验收结果 |
| --- | --- | --- | --- |
| T00 基线提交 | 无 | 检查提交范围并提交当前工作区 | 在业务代码修改和数据清理前记录提交ID，不推送 |
| T01 预设配置 | T00 | 八列数据库合同、统一节点 schema、完整默认预设 | 六固定系统节点、两个 postprocess 节点；节点无专用附加字段；摘要指令唯一存于context_strategy.summary_prompt；预设无Agent/工具配置 |
| T02 存储与接口 | T01 | repository、目标schema、旧数据清理、CRUD、导入导出、ETag | 字段单一来源；只接受目标格式；清除旧预设/会话运行数据和废弃列，修正引用 |
| T03 上下文构建 | T02 | 配置快照、材料选择、节点编译、预览、PostprocessPlan | worldInfo只读取激活世界书；chatHistory组织会话状态说明、摘要正文和保留历史；提示和权限同源；实际Provider顺序一致 |
| T04 压缩执行 | T03 | 完整预算、rolling_summary、sliding_window、摘要调用 | 100%触发/60%目标；最多一次摘要；摘要仅压缩 prompt + chatHistory，无后置处理；最终重新激活材料 |
| T05 后置处理 | T01,T03 | runtime/postprocess 切分、解析、状态与建议处理器 | 裸标签、有界缓冲、可信边界；逐项状态校验；建议三条/50码点，返回临时候选；覆盖失败规则 |

| T07 前端与 SDK | T02,T06 | 节点设置、提示预览、会话能力展示、Host临时建议、SDK订阅与WorldStory | 唯一节点开关；Host按消息展示建议，新Run受理即清除；重复/迟到事件不复活建议；历史不展示建议；iframe 权限不变 |
| T08 验收与文档 | T01–T07 | 集成测试、界面检查、独立复核、相关产品文档与 AGENTS | 关键流程及边界通过；文档反映已实现行为；报告实际检查结果和限制 |

具体目标文件与目录见方案第5.1节；任务按这些文件职责实施，不建立另一套建议存储或公开事件总线。

## 2. 核心验收场景

| 范围 | 必测场景 |
| --- | --- |
| 预设 | 八列往返、零值参数、配置错误、ETag冲突、旧格式拒绝、废弃数据/列清理、目标种子与引用完整 |
| 上下文 | 原角色历史、load=never、世界书顺序、global值不自动注入任何节点、session定义与当前值来源、不读世界介绍组件或用initial覆盖当前值、摘要正文仅注入一次、输入不二次模板化、冻结快照 |
| 压缩 | 两种策略、完整输入估算、context_strategy.summary_prompt与摘要正文分离、旧摘要合并及覆盖边界、连续后缀、一次调用无重试、摘要无工具和后置处理、最终材料重新激活 |
| 解析 | 任意分块、Unicode、字符串内标签、半标签、重复/乱序/未知尾块、属性及大小写错误、旧外层拒绝、重复JSON键、32层与262144字节边界 |
| 状态与建议 | 四种开关组合；无可写根时整节点跳过、无替代提示/状态处理且不改配置；0/false/空字符串/空对象仍是有效状态；[]、无效项、重复路径、越权/类型/范围、建议数量/长度/重复校验 |
| 失败与提交 | 建议局部错误保留合法状态、结构损坏丢弃整批、模型错误/截断/终值不一致、提交前取消、tip/基线冲突、DB失败不发布成功结果 |
| 建议事件 | 仅提交成功后发送一次；sessionId/runId/assistant messageId正确；新Run持久化及诊断不含items或原始建议块；HTTP历史/恢复/终态均不返回建议文本；旧运行数据清除；事件丢失不补发 |
| Host临时展示 | 三条绑定正确消息、重复事件去重、消息暂未渲染、最新Run归属检查；新Run受理清除，发送被拒绝保留；已受理后失败/取消不恢复；迟到202不清掉同Run的新建议，迟到旧事件不复活 |
| 集成 | Agent及工具依赖已删除，连通性测试仅固定文本；Usage与输入恢复、SDK目标状态结果、刷新/重进不恢复建议、断线禁用及重连核对、建议只填草稿、375px/1280px界面及键盘交互 |

## 3. 实施与验证要求

实施前确认工作区改动和各目录 AGENTS；只改本任务范围。验证使用临时数据库和 mock Provider，不调用付费模型；正式切换按方案第7节的授权清单执行数据清理，先停服持锁，不能混用验证库与实际数据目录。

定向检查后运行 `pnpm typecheck`、`pnpm lint`、`pnpm test`、`pnpm build` 和相关浏览器测试。根脚本分别覆盖 Server+Studio 类型检查、Server lint、Server测试和Studio构建；预设交互需补充对应浏览器用例，不能以构建通过代替界面验证。

独立复核沿“预设 → 上下文 → 压缩 → PostprocessPlan → 解析 → 候选 → 提交 → 前端结果”检查单一配置来源及失败边界。实现完成后再同步正式文档；实施过程中同步记录任务状态；最终不保留废弃代码和兼容路径。

废弃清理按方案第7节逐项核销，并作为T08的阻塞验收项；不通过保留legacy文件或旧字段绕过检查。

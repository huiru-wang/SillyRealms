# 小饭馆的经营、人物与家常

## 状态与叙事

玩家经营的是一家已开了五年的小饭馆。故事从第一个可玩日开始计日。八个状态均由当前会话的消息继承；跨日不重置人物挂念、累计收入或存粮。

| 状态根 | 记录依据 | 开局 |
| --- | --- | --- |
| 时日与场景 | 跟随实际经过的日子、时段 | 第 1 日，上午 |
| 饭馆营业 | 落座、下单、上桌、收款、离席分别确认。同桌可分次上菜，已上菜保留至收桌 | 两桌客；熟客的豆腐已上，米饭两碗、炒青菜一盘待上，另一桌的点单未知 |
| 食材余量 | 采买、盘点和实际耗用改变余量，洗切只改变备料。数量可用自然单位、约数或“未点清” | 青菜洗净，五花肉切片，鸡蛋一篮 |
| 收支账 | 从开局累计实收营业收入，单位为文。实际收款且金额明确时更新总数 | 0 文 |
| 掌柜 | 所在位置供页眉与场景取色共用，手头事和挂心事按玩家已表达的事实更新 | 大堂给熟客上豆腐，想给鱼儿扯花布 |
| 李鱼儿 | 本人所在位置、手头事、挂心事；关心别人的事仍归她本人 | 大堂看店，惦记给妹妹做裤子 |
| 李鸟儿 | 使用同样三个字段，只记玩家已知的事 | 在大堂陪熟客说话，想吃糖葫芦 |
| 家常记事 | 短句字符串列表。模型按故事进展自行增补、合并或移除，每项一事 | 鱼儿提醒：豆腐多煨一会儿才入味。 |

## 账页与使用

桌面以正文为主，右侧按堂口、角色、粮柜、家常翻页。手机页眉显示当前时地和待上菜品行数，点开底部账页。堂口展示累计实收、营业阶段、客桌数和各桌客单。角色页依次列出掌柜、李鱼儿、李鸟儿的位置、手头事和挂心事。粮柜逐项对照余量和备料，家常页逐条展示短句。舞台从 SDK 读取已提交状态，翻页只改变本地视图。

新版舞台能投影旧快照中的场景、菜单、人物和菜谱。已经导入的旧卡与其存档仍属于原世界实例；导入新包并创建会话即可从新定义开局。

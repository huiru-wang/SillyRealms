## 2. 九个实施任务

| 任务与依赖 | 要交付的行为 | 可单独验证的完成条件 |
|---|---|---|
| T1 固定首发协议与能力基线 | 逐项登记当前入口、用户操作、Server 身份及资源语义，把公开类型、两份代理表和导出清单转成编译可检查的定义。记录默认舞台、雾港、世界介绍预览在桌面及窄屏的基础行为 | 标出每个旧 hook/界面分别迁到哪；7 个 hooks、2 个原语、8 个内容事件及示例都能在作者白名单环境编译；协议层可以在 Server 无 DOM/React 环境引用。SDK 不暴露语言状态或翻译接口，错误与草稿失败按原因码验收；输入区文案及译文不列入首发重构验收 |
| T2 建立作品装载（依赖 T1） | 先制作只画标题的普通官方根，走初始包安装。实现缺省根选择、两个版本化模块图、世界素材与舞台素材解析、显式恢复；带入作品本身的消息替换 | 干净安装后 A 无根能打开 B；A 有根时不需要读取 B 的模块；A/B 同名组件和图片不串；配置错误和坏根有可复现诊断。两个包更新、删除与重新安装后无陈旧模块 |
| T3 建两种薄 Host 和空 frame（依赖 T1） | 会话页单条 SSE，共享端口握手与清理，分离 preview 操作表；完成 mounted、ready、连接变化、外观下发、取消/超时和请求归属 | 从建立 SSE 后连续重载三次 iframe，连接数恒为一；无端口时业务事件不再出现于新帧。同一会话的两个标签各一条，切换会话无旧回调；重复/过时代次、错误来源、未知操作、越界预览请求均拒绝 |
| T4 打通读写与世界预览（依赖 T2、T3） | 用受限投影接现有 HTTP，补齐状态 target/scope/paths/updates 映射。先交付独立加载的天气牌、角色信息和资源；恢复只读预览的隐藏、焦点和尺寸 | 进程内 app.request 验证会话三域、预览 global、缺失/null、空列表、重复路径、批写部分失败、锁与无权子资源。天气牌在预览环境零会话请求；在会话舞台仅有 SDK 的 limit=1 校准，无阅读器分页请求；预览池最多十个，FIFO、重试撤桥、退出中断加载均通过 |
| T5 打通一轮完整叙事（依赖 T3、T4） | 实现 useSRSession 的只读 status、三个配置原值、send、异步 setDraft、runs.query 与 events.subscribe。SDK 安装端口监听后立即发 limit=1，每次重连重新校准；run.delta 和已保存助手消息分开投影正文与思考文本。WorldStory 先监听再查询，自持阅读窗口；验证视觉小说只读一轮，地图只发行动。SDK 按执行身份交付终态 | 用户在地图点一个按钮即能保存一轮。分别交换 HTTP 与 SSE 到达顺序；重载于生成中、漏 final snapshot、漏终态、旧请求晚到、删除/seq 复用、停止保留部分正文、结算失败，最终 UI 与实际记录一致且零自动重发 |
| T6 完成 iframe 交互和可选领域（依赖 T4、T5） | 会话 FrameShell 常驻平台 Composer 与作者根；发送、编辑、停止/帮答/重新生成、收起焦点与胶囊栏均由平台控制。作品只用公开接口直接发送或填稿。三个会话开关配置从存储直达 SDK，建议和立绘 hook 只读最新普通消息 | 作品 send 保留正在编辑的草稿，平台提交受理只清匹配修订；跨标签帮答、重载、停止及 SSE 抢先返回正确；受理清空建议且迟到确认不清新建议；实时立绘直读 asset，最新消息缺失/失败/空立即清场，零父链回溯；开关与是否登记立绘胶囊无关；独立读窗不争滚动位置 |
| T7 发布完整官方舞台与作品示例（依赖 T2、T6） | 替换标题根为正常卡内的阅读、立绘等组件；把雾港及所有内置源码改用新接口。用另一张卡随包带入替换组件。缺少可维护源的内置 ZIP 先核对内容，使用当前卡工具解包/保存源码再改动、重打 | 相同官方源码换包 ID 仍具备完整能力。地图根用公开 send 完成一轮，平台输入仍可收起再展开；只换阅读器或立绘不会影响发送。世界介绍/角色/开场显示仍可独立使用。中文 IME、粘贴、角色扮演、阅读定位、窄屏键盘、安全区、焦点、降动效和主题均覆盖 |
| T8 删除旧通路并对齐运营面（依赖 T5–T7） | 移除 workspace、StageSnapshot 消息、Host 草稿/按钮、frame 内置根、旧 SDK 导出及专属样式入口。运营顶栏集中用量、摘要进度、返回、设置、显式恢复；停止仅在平台输入区触发（收起时仍可达）；管理功能保留。更新 docs、AGENTS、作者指南和示例所用 API | 正式舞台构建无旧公开入口与快照协议引用；没有 SDK 子路径供卡绕过包根。五个管理页、创建/配置会话、模型/预设设置、世界管理/发行更新可用；同页改主题或显示名不会重置阅读。坏消息部件局部降级，坏根时能重试/退出/显式使用默认舞台 |
| T9 首发候选验证与放行（依赖 T8） | 用同一 Git 修订生成 Web/隔离构建、内置 ZIP、公开 SDK 类型及示例；按下表分别记录静态、真实导入、试玩和故障恢复。上线以单一首发版本部署 | 通过各层验收，产品用例实际跑通，有对应卡版本/复现方式和结果。回撤演练使用上一套已验证的整组候选构建及其独立测试数据根，不提供线上兼容入口，不删除玩家数据 |

T2 和 T3 可以独立开发。第一次纵向验收为 T5 的“无聊天列表也能完成一轮”，第二次为 T7 的“换包 ID 后仍能复现官方体验”。这两个节点能在删除旧实现前发现边界缺口，避免一次搬完才发现仍需私有 API。

## 3. 首发放行记录要求

| 验证层 | 具体证据 |
|---|---|
| 静态及打包 | 根目录运行 pnpm typecheck、pnpm lint、pnpm test、pnpm build。检查两个 frame HTML、CSP、SDK 根的运行时导出和发布类型。用仓库 world:check、world:pack 检查并打包受影响的世界；用 world:release 在临时目录生成并检查发布清单，不把演练自动发布到远程 |
| 函数与协议 | 使用现有 Server app.request、既有路由及真实的领域归并函数验证 SDK → 操作表 → HTTP。验证成功、403/404、锁、取消、写回执丢失、错端口响应和事件乱序。查询期间插入删除与终态；观察去重键、无重发和最后可见消息，不靠固定延时令测试通过 |
| 资源和访问边界 | 以相同组件在预览和会话运行；检查预览拒绝 session/message、写入和帮答；会话代理拒绝自定 URL/目标、越会话 entry 与未绑定帮答请求。管理凭据、模型配置密钥、私有帮答目标和原始内部行不出桥。资源加载验证包内路径、缺图、素材换版及同名解析 |
| 状态保鲜 | 在无作者组件、纯天气牌、多个 useSRSession 消费者三种会话舞台，已连接时首次绑定各发一次 limit=1，每次重连成功各补一次；卸载/重挂子组件不增加请求，预览为零。模拟首次读早于 SSE 就绪、断网期间完成、读失败后自动重试、不同代次响应及同轮重生成乱序。即使作者从不订阅事件或查询轮次，status 也从 unknown 恢复到正确状态，过时结果不能回退新状态 |
| 会话配置与立绘 | 三开关分别在创建、保存、刷新后逐项相等；空素材目录、有云端素材或缺帮答预设均不改写 true。最新玩家输入、无有效立绘/显式空、重新生成和过期事件均不继承旧画面；只对最新助手补读，不翻旧页。开关关掉仍能声明并点击角色胶囊，作者决定反馈 |
| 固定输入与草稿 | 普通根、官方根和抛错根均保留一个平台 Composer；收起、展开后草稿及胶囊保留，收起仍可停止。作者 SDK 类型与实际注入模块均无 stop、regenerate、assist、草稿读回或编辑器，平台实际可执行这些操作。setDraft 检查成功、清空、帮答占用、超长及已撤销绑定；失败保留原稿，离线可填，作品 send 不擦草稿 |
| 胶囊与布局 | 同一 frame 多组件、同名标签、回调更新、卸载及根错误恢复后无重复或陈旧回调；登记和点击的端口消息均为零。验证零项、一项、刚好容纳、超过五项、长标签及窄屏；空行不占位、等宽单行、容得下居中，溢出裁切且首尾均可横滑到达，Tab 依次聚焦并滚入视口。配置开关和无目录场景不改变登记 |
| 流式思考 | 以仅正文、仅思考、两者同片、仅工具四种分片验证字段投影和跨桥次数；验证完整快照覆盖两个字段（含清空）、纯思考助手消息的持久轮次回读、中途重载恢复、同轮重新生成后旧回复思考不串入新回复。帮答和用量边界各自验证 |
| 作者契约 | 断线/首屏为 unknown、受理至终态为 generating、确认空闲为 idle；停止请求不提前变 idle；生成零正文也能结束。按轮验证 limit=1/5、非法 limit、错误 cursor、最后一页、开场与只有玩家的轮。两次独立查询互不移动窗口；查询遇到删除、同轮换回复和迟到增量时不复活旧正文 |
| 订阅与顶栏 | 内容订阅只接未来指定类型，验证多类型判别、重复类型、退订、监听器异常，以及空列表/未知名/通配符拒绝。抓取真实端口投影，八种公开事件只带允许字段；计量、摘要、模型诊断从平台可读但零次过桥。跨标签帮答正文只到发起端口，预览没有会话事件 |
| 负载与释放 | 同段 delta 在 5 轮和 50 轮已加载历史下，跨桥均为同一事件、字节数与历史无关。十个组件监听同一事件只跨桥一次、各监听器分别处理，取消订阅不重建 SSE；卸载最后一个内容消费者后停止相应的内容查询，会话 SDK 继续维护状态直到撤桥。重复切换会话和预览淘汰后，检查存活端口、订阅、计时器和读请求数量回到预期 |
| 真实安装和导入 | 独立空数据根验证 manifest 启动与官方包可读；分别真实导入显式根、缺省根、可替换部件样例。记录包 ID、发行版、导入回执、绑定作品与默认根来源。对损坏发行物另记导入拒绝或运行诊断，不把静态通过作为导入成功 |
| 真实试玩 | 在默认内容根及作者根中分别验证开局、作者直接发送、平台输入区发送/停止/重生成/帮答、状态、建议、立绘和刷新。两个场景均从平台顶栏检查用量。再测双标签交错提交、生成中重载、世界换版、断线再连、预览管理、手动救援。移动端测输入法和键盘不遮正文，桌面测焦点和返回；记录候选构建及实际观察 |

**阻断首发的情形**包括官方包依赖私有通路、预览能执行会话写入、旧执行覆盖新执行、已结算消息丢失/重复、草稿自动重发、重连触发模型调用、世界与舞台素材串用，以及 Host 重新持有业务缓存。仅在 reload 窗口看不到早先未存分片属于已界定的首发能力；必须显示正确活动状态，并在完整输出或终态查询到达后恢复正文。函数级集成使用现有进程内入口；真实导入和试玩另列放行结果，本次方案编写不启动服务。

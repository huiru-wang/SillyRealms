# 黎安世界卡构建任务

以下是后续制作顺序与完成判据。依据见[转换方案](./黎安世界卡-转换方案.md)。

1. **建立原卡映射清单。** 将 71 条世界书、6 条正则、5 个脚本和首页中的动作逐项归到目标字段或替代机制；标明默认状态、运行时启用条件、只读资源和酒馆存档专属功能。
2. **制作双主角与单一开局。** 写入玩家、黎安与按需 NPC、无剧透介绍、马车定稿和完整初始状态。验收时创建会话应只产生一条开场，首轮从玩家行动接下去。
3. **接通建角与状态。** 在会话内保存身份、五问、难度及要素，为剧情动态值添加 State V2 规则。检查五问答案能影响模型看到的玩家人设、年龄与填写值一致、分开行动时两人地点可独立变化，两个会话可持有不同设置。
4. **重写世界书加载条件。** 配置常驻背景、地域、修炼、语料、五阶段、九路线、六爆发点和自定义路线。用上下文样例验证传闻不能登记真相、启用线路不能提前兑现结局、组织变故后继续同行仍保留原阶段。
5. **还原地图与十五个节日。** 整理地点资料和原历表，完成自动与手动的节日选择。验证翻地图不会移动人物，手动选节仅影响本局，回忆节日、公农历冲突和超出历表范围均不会误触发自动节日。
6. **完成舞台与原生后处理接入。** 接入故事流、状态、武学、地图、线路、阶段、设置及本局编辑。用已提交状态验证刷新恢复；检查正文、历史和上下文都不会混入旧首页、占位符或 MVU 更新指令。
7. **打包并验收。** 生成带署名的世界卡 ZIP，使用现有导入解析器检查资源和组件引用，对开局、跨年、首次揭密、组织变故后分别、两局隔离做函数级回归，并运行适用的类型与 lint 检查。

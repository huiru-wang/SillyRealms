## 复现

从仓库根目录运行，需要本项目已安装的 pnpm 依赖和 Google Chrome：

```sh
python3 'data/角色卡/窗边的女人/世界卡/构建.py'
pnpm build
pnpm --filter @sillyrealms/server exec tsx "$PWD/data/角色卡/窗边的女人/世界卡/验收/server.mts"
```

隔离服务输出 `ready` 后，在另一个终端运行：

```sh
node 'data/角色卡/窗边的女人/世界卡/验收/browser.mjs'
```

每次完整复跑应重新启动隔离服务，避免上一轮合成对话影响“首局”断言。结束后向隔离服务发送 Ctrl+C；它将关闭内存库、删除自身临时附件目录并保存 `runtime-results.json`。不要将脚本改成用户数据库路径。

相关回归测试实际命令：

```sh
pnpm --filter @sillyrealms/server exec vitest run test/direct-runtime.test.ts test/world-components.test.ts test/creator-components.test.ts test/opening-state-preview.test.ts
```

# 小饭馆：世界介绍与角色头像

本次完成介绍页面和头像素材，尚未组装或导入完整世界卡。原角色卡、世界书、开局和项目应用代码均未修改。

## 查看

- `index.html`：自包含离线预览，可直接用浏览器打开；图片、React 和样式均内嵌，无外部请求。
- `WorldIntroduction.tsx`：世界介绍组件源码。
- `Portraits.tsx`：生成的卡内资源模块，供介绍组件默认导入。
- `世界介绍.fragment.json`：将其中 `description` 和 `components` 合并到最终世界卡的 `data`，不是独立可导入的世界卡。
- `角色头像映射.json`：三个角色的稳定 ID 建议、头像值、可扮演标记和来源。最终组卡时按角色合并 avatar，不以本文件覆盖完整人物 prompt/description。

## 页面内容与边界

- 玩家身份：掌柜；姐妹为不可扮演 NPC。这里只展示资料，人物切换不改变会话角色。
- 介绍覆盖大离京城的市井背景、三人的亲人关系、买菜、做饭、试菜、跑堂、记账与闲时生活。
- 封存往事不进入介绍文案。无新增经营数值、恋爱机制、江湖冲突或虚构门店地址。
- 视觉取原图的暖光、木色和朴素衣料；纸色底、宋体标题、朱砂色主操作。颜色来自生成的 paper/stove 色阶。
- 组件仅使用 React 和 `./Portraits` 默认导入；不依赖 SDK 状态、会话 API、Server HTTP、父窗口 DOM 或浏览器存储。
- 介绍组件总源码约 726 KiB，满足单组件 1 MiB、组件库合计 2 MiB 的约束。

# Server V2

- 按模块逐步迁移；当前实现 `src/events/` 及最小 HTTP 启动入口，不预建 engine、任务管理或应用通知。
- 事件连接独立于业务执行。业务发布完整事件；连接层不得查询 Runtime、数据库或决定业务终态。
- 会话运行完成、失败、停止均不关闭 SSE；断开连接只取消订阅，不取消业务。
- 本模块不持久化或回放事件。接入路由时由调用方负责会话存在性、访问校验及业务结果查询。
- 事件仅包含 `event` 和 `data`；不生成事件 id，不输出 SSE `id:` 字段。
- 会话存在性与访问检查由路由侧的 `canAccessSession` 接入；未接入时返回 503。测试夹具不得成为启动入口的默认会话存储。
- HTTP 集成测试使用真实回环端口和业务侧 publish，禁止为测试增加公开事件发布接口。关闭服务须结束 SSE 并停止监听。
- 事件模块改动运行本包测试、类型检查和 lint；生命周期约束见 `../../docs/runtime/server-v2-events.md`。
